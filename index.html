Pasa el ratón por el dibujo para ver la posición de cada bloque.

Ratón: clic o arrastre marca como construido · clic derecho desmarca · Ctrl + rueda: zoom hacia el puntero · en pantalla táctil, pellizca para hacer zoom. Teclado (con el dibujo enfocado): flechas para moverte (Mayús = 5), Espacio o Intro marca/desmarca, RePág/AvPág cambia de capa, + / − zoom, 0 ajusta. Ctrl+Z / Ctrl+Y: deshacer / rehacer.
